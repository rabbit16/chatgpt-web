# 发票功能说明（按充值订单开）

> 2026-10-22 · 按站长反馈改造：**发票必须绑定一笔已支付的充值订单，一单一票，入口在支付记录里。**

## 用户怎么用

1. 打开「价格与充值」→「余额与充值」；
2. 往下找到「支付记录」，每一笔充值右侧有「发票」列；
3. 点「开发票」，金额和订单号自动带出，只填抬头类型、名称、税号（企业）、邮箱、备注；
4. 提交后在「我的发票」（头像菜单）看状态：待审核 / 开票中 / 已开票 / 已驳回；
5. 审核中可撤销；驳回后可回到支付记录「重新申请」；已开票不能再开。

充值成功后页面会自动弹一个「充值成功」提示，可直接跳到支付记录开发票。

## 为什么这样改（站长原话）

- 不能在任意页面随手开票，否则用户会“随时随地大小开发票”，审核很烦；
- 用户应该在**支付记录**里找到那笔充值，再点开发票；
- 开过的订单不能再开。

## 后端要做的（详见 `docs/api/invoice.md`）

- `user/invoice/create` 改为接收 `bill_id`，金额由后端按订单取；
- 校验：订单属于当前用户、已支付、未开过（pending/issuing/issued 都算已开）；
- `user/invoice/list` 每条返回 `bill_id`；
- 建议 `user/user_bill_list` 每条加 `invoice_status`，支付记录就不用二次对照；
- 管理员审核通过时再次校验同一订单没有其他有效发票。

接口没上线时：支付记录发票列显示「开票服务未开通」，「我的发票」显示空态，不会弹技术报错。

## 验收清单

- [ ] 未开票订单显示「开发票」，能打开弹窗且金额正确；
- [ ] 提交后变「待审核」，重复点提示已开过；
- [ ] 驳回后变「已驳回」，可重新申请；
- [ ] 通过后变「已开票」，不能再次申请；
- [ ] 后台列表能看到订单号，同一个订单不会出现两张已开票；
- [ ] 1440 / 390、浅色 / 深色都不破版。
