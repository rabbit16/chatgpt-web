## 二、改了什么

### 1. 恢复独立页面 `/agent`（新建 `src/pages/agent/index.tsx`）

原来 `/agent` 是个跳转（`<Navigate to="/guide?tab=client">`），等于页面没了、接入内容全压在教程里。现在换成真正的页面。

首屏置顶一张「复制这两个值」卡，一次给齐：

| 值 | 内容 | 复制按钮 |
|---|---|---|
| 接口地址 | `https://www.rabbitj.top/v1`（OpenAI 兼容，必须带 `/v1`） | 有 |
| Claude 专用地址 | `https://www.rabbitj.top`（Anthropic 原生，不带 `/v1`） | 有 |
| API 密钥 | 打码显示，复制拿到全文 | 有（主按钮） |
| 两个模型名 | `gpt-6.1-sol` / `claude-sonnet-5` | 有 |

密钥从「要先生成才能看到的操作区」提升到置顶面板——这正是客户「找了半天」的根源之一。

### 2. 导航：新增独立「接入」项

- 新增「接入」（`/agent`，`ApiOutlined`，与历史版「Agent 接入」同图标）
- 原「接入指南」改名「接入教程」
- **「接入」排在「接入教程」之前**，否则用户又被引去教程

两项措辞拉开：接入 = 拿值，教程 = 照着填。

### 3. 教程页 `/guide` 不再重复渲染那两个值

第 2 步整块复制界面删除，压成一句说明 + 一个主按钮「去接入页拿地址和密钥」。复制 UI 全站只留 `/agent` 一处，以后换域名不会漏改。

### 4. 全站落地页跳转改指 `/agent`（5 处）

| 位置 | 原来 | 现在 |
|---|---|---|
| 首页两张特性卡 | `/guide` | `/agent` |
| 充值成功弹窗按钮 | `/guide` | `/agent`，文案「去接入」 |
| 绘图页「无密钥」提示 | 纯文字、无入口 | 加按钮跳 `/agent` |
| 价格页「还没有密钥」 | `/guide`，文案旧名「接入指南」 | `/agent`，文案「去接入」 |
| API 报错文案 | 「Agent 接入」 | 「接入」 |

### 5. 顺手修掉一个安全项（重要）

`ApiKeyPanel` 原来把**完整密钥明文**渲染在页面上，整页截图或录屏就能被 OCR 读走全串。现在列表显示打码值（`sk-38b8****b38f`），**复制按钮仍复制完整密钥**。

## 四、过程中发现并修掉的问题

这三条都是验收/设计独立查出来的，不是我一开始想到的：

1. **手机端地址被截断**（最危险）——改 `nowrap` 后 `code` 只有 156px，屏幕上只剩 `https://www.rabbitj`，`.top` 和 `/v1` 看不见。用户照抄必连不上，比折行更糟。已修为值独占整行。
2. **手机端密钥在首屏外**——差 45px（top 849 > 视口 844），iPhone 13 更差。已通过收紧 Hero 间距 + 值区两段式排布解决，密钥降到 736。
3. **密钥明文显示**——安全问题，已打码。

中间我一度把值和按钮排成同一行（密钥进首屏了），但地址又被压窄裁掉了 `/v1`。**两个条件必须同时满足**，最终选择「值独占一行、按钮下一行右对齐」——宁可多一行，也不能让地址不完整。
