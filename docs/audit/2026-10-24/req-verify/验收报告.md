## 三、必须修（2 条，均不阻塞站长原话需求，但属规格明写未做到位）

### 1. 搜索命中片段无高亮（规格 §2.2、§3、§5d）

- **页面 / 视口**：`/price`，1440 与 390 均如此
- **现象**：搜 `gpt` 时结果行里 `gpt-6.1-sol` 与其它文字完全同色同权重，`mark` 数恒为 0。空格分词（如 `gpt sol`）命中 4 条时，用户**看不出是哪几个词命中的**，只能逐条肉眼比对。
- **精确改法**：
  1. `src/pages/price/index.tsx` 组件内新增纯函数（`terms` 已在作用域内，`columns` 是普通数组可直接闭包引用）：

     ```tsx
     const HIGHLIGHT_RE = (t: string[]) => new RegExp(`(${t.map((x) => x.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')).join('|')})`, 'ig')
     const highlight = (text: string, t: string[]): ReactNode => {
       if (!t.length) return text
       const re = HIGHLIGHT_RE(t)
       const token = new RegExp(`^(?:${t.map((x) => x.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')).join('|')})$`, 'i')
       return text.split(re).map((part, i) => (token.test(part) ? <mark key={`${part}-${i}`} className={styles.hl}>{part}</mark> : part))
     }
     ```
  2. 同文件「模型」列 `render` 内两处替换：`{record.name}` → `{highlight(record.name, terms)}`；`<div className={styles.modelCellId}>{record.id}</div>` → `{highlight(record.id, terms)}`
  3. `src/pages/price/index.module.less` 新增一条（规格给的精确值）：

     ```less
     .hl { background: var(--brand-soft); color: inherit; font-weight: inherit; padding: 0 1px; }
     ```
     （`--brand-soft` 深色下已是 `#2b3546`，无需新增变量）

### 2. Esc 不能清空搜索（规格 §3「清除」行）

- **页面 / 视口**：`/price`，1440 与 390
- **现象**：输入 `gpt` 后按 Esc（连按两次）→ 输入框仍为 `gpt`、仍 13 行、（规格要求焦点回到输入框）。点 ✕ 清除则完全正常（清空、回 15 行、焦点回到输入框）。
- **精确改法**：`src/pages/price/index.tsx` 的搜索 `<Input>` 增加：

  ```tsx
  onKeyDown={(e) => {
    if (e.key === 'Escape' && search) {
      e.preventDefault()
      setSearch('')
    }
  }}
  ```

## 四、可接受小瑕疵（列出，不要求改）

1. `enterKeyHint="search"` 未设置：实测 `enterkeyhint=null`（规格 §5 曾建议补）。手机键盘不显示「搜索」键，但输入即筛，不影响使用。改法：`<Input enterKeyHint="search" />`。
2. 桌面命中数未按规格放在「页签行右端、基线对齐」，而是**另起一行、整行左对齐**（实测页签槽 y 885–921，命中数行 y 915，左边缘与页签同为 x 160）。视觉不破版，且与手机端规则一致，可接受；若要对齐规格需把 `.searchMeta` 从块级改为与 `.tabs` 同行右侧。
3. 清除图标 12px（规格写 14px），热区 12×19。点击可用，略小于规格。
4. 搜索框左右内边距 11px（规格写左 34 / 右 32，为图标与清除位预留）。实测图标 x=962（框 x=950），视觉留白正常，不贴边。
5. 后台「隐藏」与「删除」**同为危险红**（浅色均 `rgb(240,68,56)`、深色均 `rgb(214,99,99)`），仅靠文字与 Popconfirm 区分。措辞区分已满足站长要求，且有二次确认兜底；若想进一步防误点，可给「删除」加 `type="link" danger` + 图标 `DeleteOutlined`，或把「隐藏」降为 `type="link"` 默认色。
6. 中文搜「智谱」得 0 条 —— 属规格 §6 已声明的限制（只搜模型名/ID，不搜厂商名，`glm` 可命中 4 条），**非缺陷**。
