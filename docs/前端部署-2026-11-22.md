## 顺带修复：安装包下载被 SPA 吞掉

**现象**：`GET /downloads/*.zip` 返回 `text/html` 的 `index.html`（1855B），
用户点下载会拿到网页而不是安装包。

**原因**：`location /` 里的 `try_files $uri $uri/ /index.html =404;` 位于
rewrite 之前；而放行静态附件的 rewrite 只覆盖
`js/map/css/png/jpg/gif/ttf/woff/woff2/svg/otf/eot`，**没有 zip 等安装包后缀**，
于是存在的 zip 也被回落成 SPA 入口。

**改法**：在 `/www/server/panel/vhost/nginx/chart.top.conf` 的 `location /` 内，
`try_files` 之后、`rewrite ^/(.*)/$ ...` 之前加一条：

```nginx
# 安装包与静态附件：直接命中文件，避免被 try_files 回落成 SPA 页面
rewrite ^/(.*)/(.*\.(zip|7z|rar|AppImage|pkg|dmg|exe|msi|deb|rpm|tar\.gz)$) /$1/$2 break;
```

原配置备份：`/tmp/chart.top.conf.bak.<时间戳>`。
执行 `nginx -t` 通过后 `nginx -s reload`。
